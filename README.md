# Isoform

Редактор изометрических иллюстраций в стиле сайта Passwork. Интерфейс как в Figma: слева слои, справа свойства, снизу инструменты.

- **Один примитив — блок.** Плита — тот же блок толщиной 8.
- **Один стиль** — как на сайте: линии, грани цвета страницы, при наведении синий; светлая и тёмная тема.
- **Два состояния** — вкладки «Дизайн» и «Наведение». В наведении двигаете и меняете блоки так, как они должны встать: сдвинутый блок поедет, изменивший размер — перерисует контур.
- **Превью** справа — сцена точно в кадре карточки сайта, с той же анимацией.
- **Шаблоны** — восемь сцен с сайта в «Новый файл»; открываются как копия.
- **Привязки** — блоки прилипают к краям, центрам и верху соседей (красные направляющие); ⌘ — без привязки.
- **Буфер обмена** — ⌘C / ⌘X / ⌘V, в том числе между файлами; вставляется и JSON сцены, который напечатал агент.
- **Таймлайн** на вкладке «Наведение»: задержки тянутся мышью, ▶ проигрывает на превью.
- **Расстановка** — выравнивание и равные промежутки по X, Y и высоте; отражение и поворот на 90° вместе с анимацией; ⌘D повторяет последний сдвиг копии; волна задержек одной кнопкой.
- **Проверка на лету** — у пересекающихся блоков в слоях значок-предупреждение.
- **Экспорт** — SVG в разметке сайта, PNG 2× в текущей теме и JSON-исходник; JSON открывается обратно перетаскиванием в окно или ⌘O.

## Запуск

```bash
npm install
npm run dev
```

`http://localhost:8790`. Ваши файлы — `files/*.json`, шаблоны — `templates/*.json` (не редактируются). Всё сохраняется автоматически; файл, изменённый на диске, сразу обновляется в редакторе, и это изменение можно отменить ⌘Z.

`npm run build` собирает статическую версию без сервера: шаблоны встроены, файлы хранятся в браузере (в шапке — метка «Браузер»).

## С Claude или Codex

Иллюстрацию не обязательно собирать руками. Откройте эту папку в Claude Code или Codex и опишите, что нужно — в Claude Code есть команда `/illustration <описание>`. Агент прочитает формат и правила серии в [AGENTS.md](AGENTS.md), соберёт сцену (JSON или рецепт на `src/kit.ts`), проверит её и посмотрит на PNG-превью. Файл сразу появится в открытом редакторе: изменённые блоки мигнут, а изменение можно отменить с плашки.

Обратно — правый клик по блокам → «Копировать для агента»: в буфере окажется промпт с файлом и этими блоками.

```bash
npm run scene example-vault      # рецепт recipes/example-vault.ts → files/example-vault.json
npm run render vault             # previews/vault.png: покой и наведение рядом
npm run check vault              # ошибки (✗) и предупреждения (!)
```

## Клавиши

`V` выбор · `H` или пробел — рука · `B` блок · `P` плита (тяните по полу или по верху блока) · `Alt` + тащить — по высоте · `Shift` — шаг 10 · `⌘` — без привязки · `⌘C` `⌘X` `⌘V` · `⌘D` дублировать · `[` `]` порядок · `⇧⌘H` скрыть · `⇧⌘L` заблокировать · `1` `2` дизайн / наведение · `⇧1` вписать · `⌘\` скрыть панели · `⌘O` открыть JSON · `?` все клавиши. В полях работает арифметика: `120/2`, `(40+8)*3`.

## Проверки

```bash
npm test          # шаблоны экспортируются как SVG на сайте, логика привязок, буфера, выражений
npm run check     # файлы в files/: формат, пересечения, парящие блоки и прочее
```
