# Isoform

Редактор изометрических иллюстраций для сайта Passwork. Только то, что нужно этой серии:

- **Один примитив — блок** (прямоугольный брусок). Плита — это тот же блок толщиной 8.
- **Один стиль** — как на сайте: линии, грани цвета страницы, правые грани чуть темнее, при наведении синий. Цвета взяты из токенов сайта, светлая и тёмная тема.
- **Два состояния** — «Покой» и «Наведение». В режиме наведения двигаете и меняете блоки так, как они должны встать; сдвинутый блок на сайте поедет, изменивший размер — перерисует контур (как ящик сейфа).
- **Карточка** справа показывает сцену точно в кадре сайта: масштаб по площади силуэта, одинаковый для всей серии, та же анимация и тайминги.
- **Серия** — все сцены рядом, чтобы сверять вес и непохожесть.

## Запуск

```bash
npm install
npm run dev
```

Откроется `http://localhost:8790`. Сцены лежат в `scenes/*.json` и сохраняются автоматически, по одному блоку на строку.

## Управление

| | |
|---|---|
| Тащить блок | по полу (X/Y) |
| Alt + тащить | по высоте (Z) |
| Ручки Ш / Г / В | ширина, глубина, высота |
| Shift | шаг 10 вместо 2 |
| Shift/⌘ + клик | несколько блоков |
| ← → / ↑ ↓ / Alt ↑ ↓ | сдвиг по X / Y / Z |
| B / P | новый блок / плита (с выделением — ложится сверху с зазором 10) |
| ⌘D | дублировать вправо с зазором |
| [ / ] | назад / вперёд в порядке отрисовки |
| 1 / 2 | покой / наведение |
| F | вписать сцену |
| ⌘Z / ⇧⌘Z | отменить / вернуть |

Порядок в списке — порядок отрисовки: верхний блок перекрывает нижние. «По глубине» сортирует автоматически; сплетённые конструкции (кольца вокруг фигуры, ящики в корпусе) после этого поправьте вручную.

## Выгрузка на сайт

Кнопка **«Выгрузить на сайт»** или из терминала:

```bash
npm run export            # все сцены
npm run export storage    # одна
```

Пишет `<имя>.svg` и `<имя>.scene.json` в папку из `isoform.config.json` (по умолчанию `../passwork/src/art/isoform`). SVG — ровно та разметка, которую ждёт сайт: `data-object`, `data-face`, контур, `data-open` для морфов, `data-hit`.

Хореография наведения для сайта пока живёт в `passwork/src/motion/isoform-motion.js`. Сдвиги и задержки из редактора туда нужно перенести (форму возвращает `siteMotion()` в `src/render.ts`); морфы уже приходят в SVG.

## Тесты

```bash
npm test
```

Проверяют, что восемь сцен сайта экспортируются байт в байт как SVG, которые сейчас на сайте (`test/fixtures`), и что их движение совпадает с `isoform-motion.js`.
