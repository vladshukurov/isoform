# Isoform

Редактор изометрических иллюстраций в стиле сайта Passwork. Интерфейс как в Figma: слева слои, справа свойства, снизу инструменты.

- **Один примитив — блок.** Плита — тот же блок толщиной 8.
- **Один стиль** — как на сайте: линии, грани цвета страницы, при наведении синий; светлая и тёмная тема.
- **Два состояния** — вкладки «Дизайн» и «Наведение». В наведении двигаете и меняете блоки так, как они должны встать: сдвинутый блок поедет, изменивший размер — перерисует контур.
- **Превью** справа — сцена точно в кадре карточки сайта, с той же анимацией.
- **Шаблоны** — восемь сцен с сайта в «Новый файл»; открываются как копия.
- **Экспорт** — SVG в разметке сайта и JSON-исходник.

## Запуск

```bash
npm install
npm run dev
```

`http://localhost:8790`. Ваши файлы — `files/*.json`, шаблоны — `templates/*.json` (не редактируются). Всё сохраняется автоматически; файл, изменённый на диске, сразу обновляется в редакторе.

## С Claude или Codex

Иллюстрацию не обязательно собирать руками. Откройте эту папку в Claude Code или Codex и опишите, что нужно: агент прочитает формат и правила серии в [AGENTS.md](AGENTS.md), запишет `files/<имя>.json` и проверит его через `npm run check`. Файл сразу появится в открытом редакторе.

## Клавиши

`V` выбор · `H` или пробел — рука · `B` блок · `P` плита (тяните по полу или по верху блока) · `Alt` + тащить — по высоте · `Shift` — шаг 10 · `⌘D` дублировать · `[` `]` порядок · `⇧⌘H` скрыть · `⇧⌘L` заблокировать · `1` `2` дизайн / наведение · `⇧1` вписать · `?` все клавиши.

## Проверки

```bash
npm test          # шаблоны экспортируются байт в байт как SVG на сайте
npm run check     # файлы в files/: формат и пересечения блоков
```
