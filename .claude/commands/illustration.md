Собери иллюстрацию: $ARGUMENTS

Работай по `AGENTS.md` (формат, правила серии, наведение):

1. Посмотри 2–3 сцены в `templates/`, выбери один ясный образ, не повторяющий их силуэт. Придумай имя — латиница, цифры, дефис — и проверь, что `files/<имя>.json` ещё нет (существующие файлы пользователя не трогай без его просьбы).
2. Напиши сцену: сразу `files/<имя>.json` или рецепт `recipes/<имя>.ts` на `src/kit.ts` и `npm run scene <имя>` (удобнее, когда есть повторы, кольца, каскады).
3. `npm run check <имя>` — исправь все ошибки; предупреждения с `!` разбери и исправь, если они правда про ошибку.
4. `npm run render <имя>` и **открой `previews/<имя>.png`** (Read): покой, середина наведения, полное наведение. Для сравнения отрендери шаблон: `npm run render templates/<имя>` → `previews/templates/<имя>.png`. Проверь силуэт, порядок отрисовки (ничего не просвечивает и не прячет соединения), правдоподобность движения.
5. Повторяй 2–4, пока проверка чистая и картинка аккуратная.
6. Коротко: что построено, что двигается при наведении, файл `files/<имя>.json`.
